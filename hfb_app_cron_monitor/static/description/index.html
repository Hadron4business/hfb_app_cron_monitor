Cron Monitor

Know the moment a scheduled action fails or stops running.

The problem

Odoo's scheduled actions fail quietly. An exception goes to the server log, the job tries again at the next interval, and nobody is told. If the scheduler stops picking a job up altogether, there is not even a log line. Invoices stop being sent, stock is not reordered, integrations go stale - and you find out from a customer.

What you get

Failure alerts

An e-mail with the error as soon as a scheduled action fails - once per failure streak, not on every retry.

Stalled-job alerts

A job that was due hours ago and still has not run raises an alert, even though nothing was logged.

Per-job control

Recipients and the stall threshold per scheduled action, with global defaults in Settings. Switch monitoring off for noisy jobs.

Event history

Failures, stalls and recoveries are kept on the scheduled action, with the full traceback, and cleaned up automatically.

No side effects

Does not change how scheduled actions run. A problem inside the monitor can never break a job.

Zero setup

Install, enter an e-mail address in Settings, done. Every scheduled action is watched from the start.

Works with all scheduled actions, including those added by other apps.
